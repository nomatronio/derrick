# Release Notifications

You can subscribe to email notifications about new versions of Derrick via
the [HashiCorp Community Portal](https://discuss.hashicorp.com/).

1. Log in or create an account on the portal
1. Visit the [`derrick-release`](https://github.com/nomatronio/derrick/releases) tag
1. Click the bell icon
1. Select "Tracking" mode

![Example screenshot of selecting tracking mode](/img/discuss-subscribe.png)

The Derrick team will create a new post with this tag for each release.

## Automation

If you are writing automated tooling to detect new versions, the following
endpoints and pages may also be useful:

- [hashicorp/derrick on Dockerhub](https://hub.docker.com/r/nomatronio/derrick/tags)
- [GitHub releases page](https://github.com/nomatronio/derrick/releases)
- [releases.hashicorp.com Derrick versions index](https://github.com/nomatronio/derrick/releases/index.json)
